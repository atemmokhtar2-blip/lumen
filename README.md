# DAF — Defensive Awareness Framework

DAF هو تطبيق توعوي دفاعي لاختبار سياسات الأمان وسلوك المستخدم أمام صفحات التصيد أو طلبات الأذونات الحساسة. أُزيلت منه عمدًا أي وظائف لجمع الكوكيز أو التخزين المحلي أو الموقع أو الكاميرا أو الميكروفون أو الشاشة، كما لا توجد قناة أوامر عن بُعد.

## التشغيل المحلي

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8080
```

ثم افتح `http://127.0.0.1:8080/`. يفحص `GET /health` جاهزية الخدمة، بينما يعرض `GET /api/v1/capabilities` القدرات المسموح بها. أي طلب كتابة إلى `/api/v1/*` يعاد بحالة `410 Gone` لأن وضع DAF الدفاعي لا يستقبل بيانات أو أوامر.

## الاختبارات

```bash
pytest -q
```

## ضوابط الحماية

تضيف الخدمة رؤوس CSP و`X-Frame-Options` و`Referrer-Policy` و`Permissions-Policy` التي تمنع الاتصالات الخلفية والتضمين والوصول إلى الكاميرا والميكروفون والموقع ومشاركة الشاشة والحافظة. تعمل صورة Docker بمستخدم غير root وتحتوي على فحص صحة.

## حدود الاستخدام

يُستخدم المشروع فقط في مختبرات مصرح بها للتوعية والتحقق من الضوابط. لا ينبغي توسيعه إلى جمع بيانات أو مراقبة أشخاص أو تنفيذ أوامر على أجهزة لا يملك المشغّل تفويضًا صريحًا لاختبارها.
